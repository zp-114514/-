# 新高考英语真题词频表（中英对照版）

一份基于新高考英语真题整理的高频词汇表，单文件 HTML，打开即用，无需联网、无需安装。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `广西高考高频词汇.html` | 主文件，双击即可在浏览器中打开 |

## 功能特性

- **中英对照**：每个词条含英文单词与中文释义
- **词频统计**：标注每个单词在真题中的出现次数 / 词频
- **搜索筛选**：页面顶部搜索框可按关键词快速查找
- **零依赖**：纯静态 HTML（内联 CSS/JS），离线可用，方便分享与部署

## 使用方法

### 方式一：本地直接打开
双击 `广西高考高频词汇.html`，用任意浏览器打开即可查看与搜索。

### 方式二：在线查看（GitHub Pages）
将本仓库开启 GitHub Pages 后，可通过链接在线访问：
`https://<你的用户名>.github.io/<仓库名>/广西高考高频词汇.html`

开启步骤：仓库 **Settings → Pages → Source 选 `main` / `(root)` → Save**，等待一两分钟即可。

新高考英语真题语料整理，词频统计见页面顶部。
